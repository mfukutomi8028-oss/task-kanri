## 1. 完成したデザイン

- **Linen / PC**: ネイビーの表紙、アイボリーの用紙、繊細な罫線、明確な余白、見開きの左ページに予定・右ページにToDoとメモ。実務用の上質な手帳のタイポグラフィを優先。
- **Linen / スマートフォン**: 見開きを単純縮小しない、単ページ縦表示。ページタブと下部ナビゲーション。主要操作は指先で押しやすく。
- **Margin / PC**: セージグリーンの表紙、くすみ色のタブや付箋、柔らかな予定行、軽い紙の模様。情報量を減らしすぎない遊び心。
- **Margin / スマートフォン**: 紙のインデックスを小さな横タブへ、予定を色付きの短い行へ、メモは付箋へ。かわいらしさを抑え、操作可能な領域を明示する。

2テーマは構造を共通化し、単なる配色変更ではなく、罫線、行、付箋、タブ、ボタンの造形で差を付ける。情報の意味色（遅延/緊急等）は共通。

## 2. デザイン検討時の共通画面・情報

- 画面: 今日、週間、ToDo、タスク、予定、業務メモ
- 2026-11-05（木）をデモ日付とする。日付移動も可能。
- 予定: 定例ミーティング、端末設定・確認、ベンダー打合せ、業務フロー確認、作業報告の整理
- ToDo: 5件中2件完了、3件未完了。表示数値とチェック状態を一致させる。
- 業務メモ: 引継ぎ情報のダミーデータ。患者情報を含まない。
- タスク: キッティング、HP修正、プリンタ設定などの一般的な業務サンプル。
- PCでは見開きレイアウト、スマートフォンでは単ページレイアウト。

現時点で **単独動作のHTMLモックをChatGPTの成果物として用意**。このリポジトリ内には画像やHTMLモックのバイナリを追加していない。

モック内で確認できる操作:

## 6. QA状態

- HTML内JavaScript構文はNode.jsの `--check` で検査済み。
- CSSはtinycss2でパースし、規則レベルの構文エラーなし。
- HTMLは外部のJS/CSS/画像/CDNへの参照なし。Firebase接続コード・localStorage保存コードなし。
- Chromium headlessの起動が実行環境でタイムアウトしたため、**視覚的なブラウザQAとクリック操作は未検証**。画面の受入前に実機の操作確認が必要。
