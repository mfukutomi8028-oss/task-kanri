# Origin Ver.664 — 個人付箋の操作改善と共通検索の調整

## 対象と目的
Ver.663のOriginを直接改修する。付箋の保存・移動・表示・位置、既存メモ、5ページ、色、折りたたみ、拡大編集、Firebase保存先を維持し、操作時の不自然な画面移動をなくす。

## 結論と設計
- **一時拡大の中央揃え**: showModalのダイアログはviewport中央に固定する。閉じた後のフォーカス・スクロールを維持する。
- **表示枠と全体表示**: 1400×900の論理ボードを保持。全体表示では外枠を縮小率に合わせた寸法へ変更して中央配置、空の配置不能領域を残さない。原寸表示へ戻す際の幅計算は親要素基準とし、ResizeObserverが自己参照で縮み続けないようにする。
- **スクロール**: 保存・変更で再描画される際、ボードの縦横スクロール、ページスクロール、操作対象のフォーカスを可能な限り保持する。利用者切替、ページ切替、意図的な検索ジャンプは例外。
- **自動整列の完全撤去**: ボタンだけでなく、実装・DBコマンド・レイアウトプランナ・関連テストを削除。既存の保存済みレイアウトには触れない。
- **任意のグリッド吸着**: 通常ドラッグは自由移動。Shift+ドラッグ中のみ現在の28pxマス目に吸着。端へはみ出さない。Shift+方向キーも28px単位で移動。AltはOS/他ソフトとの競合を避けるため使用しない。
- **注意文の撤去**: 付箋上のログイン未実装に関する注意文を削除し、ボードを上へ詰める。ただしアクセス制御の仕様は変更しない。
- **右上の検索**: PCの検索候補幅を約440pxへ拡張し、種類別タブは改行して常に全件見えるようにする。スマホは最大画面幅、横スクロール禁止。

## 品質と非対象
- Origin以外のテーマには触れない。
- 個人付箋の本文・色・位置・サイズ・ページ・ログインなし保存の既存データを維持。
- 自動保存時のスクロール復元、28px吸着/通常ドラッグ、全体表示/原寸表示、モーダル中心、検索レスポンシブをPlaywrightで検証。
- Protocol/認可/Firebase Emulator/全ブラウザ回帰、公開後資産照合で確認。
