# JOURNAL紙面ナビゲーション・操作フィードバック再設計（2026-11-14）

## 目的と利用場面
日々の作業担当者が「今日・タスク・予定」の切り替えと主要操作を迷わず実行できる、素朴で現代的な手帳UIを作る。見た目だけでなくホバー、押下、キーボード、タッチ、表示位置を一貫させる。

## 既存監査からの根拠
- 上部5タブは全面パステル、切り欠き、ホバー-4px/選択-5pxの浮き上がりが競合し、画面タイトルより派手。
- スマホ下部5タブはテキストのみでPCのアイコンと一貫しない。
- 今日の一部操作、予定検索、案件ノート操作には44px未満の対象があり、選択/ホバーの体系が分散している。
- 手帳風の厚い外枠・重い影が重複し、主役の本文より装飾が目につく（視覚評価。主観を含む）。

## 方針比較
1. **採用：静かなエディトリアル手帳** — アイボリーの紙・インク・控えめな綴じ線。選択中はインク色の帯、ホバーは影と1px程度の変化、Motion reduceで停止。既存UIを再利用し、仕事の内容を主役にする。
2. 色・動きを増やした楽しい手帳 — 個性は強いが選択状態と情報より装飾が勝つため不採用。
3. フラットな管理画面へ全面置換 — 操作は単純になるがJOURNAL固有の紙面性を失うため不採用。

## 具体仕様
- 上部の5章タブを落ち着いた紙の見出しへ変更。選択状態を色だけでなく線/形でも表示。3D切り欠きと大きな移動を撤去。
- スマホナビにもPCと同じSVGアイコンを表示。幅320/390でも5タブ、各操作44px以上。
- 今日の主案件・予定、案件アトリエ索引/カード、予定表示切替/日付移動/検索に共通のコントロール階層・押下・フォーカスを適用。選択中の項目と主動作を瞬時に識別できる。
- タッチに必要な反応は押下状態で表現し、hover依存にしない。hover演出はhover/fine環境のみ。prefers-reduced-motionで非必須アニメーションを解除。
- 紙面・3カラムの閲覧構造、既存の5タブ、Classic/Origin/Firebase/保存、モーダル・戻り・検索・フィルタ・選択・スクロール状態は維持。

## 受入基準
- 320/390/768/1366pxで操作ラベルが判読でき、横はみ出し/不正な重なりがない。
- 今日・タスク・予定の主要操作、モバイル5タブ、表示切替と検索の入力が維持される。
- デスクトップhoverが軽く反応し、キーボードfocus-visibleが明瞭。reduced-motionで意図しない移動なし。
- Protocol、JOURNAL Playwright、必要なGitHubリリース検査が成功してから統合・公開。
