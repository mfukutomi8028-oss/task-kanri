# Origin 個人付箋：ログインなし先行実装計画（2026-11-21 改訂）

**目的：** Originに付箋を追加する。Classic・JOURNALはOriginでの動作確認後に検討する。付箋専用ログインは追加せず、業務管理ボード全体の認証は将来の別工程とする。

**優先要件：** 既存のタスク／予定／業務メモ／個人ToDoと同じ利用者選択で付箋を表示し、既存Firebase接続で端末間同期する。Firebase未設定の場合は端末内保存のみ。既存機能を壊さない。

**保存先：** `rooms/{roomId}/personalStickyNotes/{displayNameKey}/{noteId}`
`displayNameKey` は、NFKC正規化、空白削除、12文字制限した表示名をUTF-8の16進文字列に変換した安定キー。既存の付箋モデルの `ownerUid` 欄にはこの表示名キーを格納するが、**Firebase AuthのUIDではない**。

**本人確認と公開制約：** 利用者名による振り分けはアクセス制御ではなく、他人の付箋への閲覧・変更を保証して防げない。機密情報・患者情報・個人情報を書かない。画面にも説明を表示する。現行 `rooms/$roomId` の匿名アクセス権は変更しない。将来の全体ログイン導入時に権限分離を再設計する。

**UI：** 付箋6色、最大2000字、PCのドラッグ・拡縮・前面・全体表示、スマホの縦一覧・並べ替え、検索、色フィルター、一覧からの再表示、未保存警告、日本語IME・キーボード操作は維持する。

**安全策：** リモート接続失敗時は端末内保存へ自動フォールバックしない。誤った二重データを作らない。ユーザー切替時に前の表示・保存操作を無効化する。Firebase接続のないローカルモードだけは端末内保存を許可する。復元用GitHubブランチ `backup/pre-origin-sticky-20261121-352457b` を維持する。
