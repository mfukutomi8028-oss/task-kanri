# Origin 付箋UX・5ページ化 改修方針（2026-11-21）
- 目的：メモの選択行を取り去り、付箋ボードの画面占有・色操作・重なり・横スクロールを改善する。
- ヘッダー「メモ」クリック：最後に開いた業務メモ／個人付箋へ遷移。デスクトップのマウスオーバー／フォーカスで２つの選択肢を表示。タッチ端末ではメモ画面の見出し横から切替可能にする。選択は利用者・ルーム別に端末内で保持。
- 付箋の色：常設の6色フッターを廃止し、コンパクトな開閉式の色選択へ。キーボード対応、44pxタッチ領域を基本とする。
- 重なり：前面に加えて背面を設ける。同一ページ内でのみ前後関係を調整。
- 表示領域：デスクトップの1400×900論理キャンバスを維持し、表示幅に自動縮小。スクロールバーの残存を防ぎ、ドラッグ座標と保存値を維持する。スマホはリスト表示。
- ページ：1〜5の固定ページ。既存付箋はlayout.pageがないため暗黙の1ページ目として表示。新しい付箋にはlayout.pageを追加して同じ保存先で同期。旧データの一括書き換えは行わない。選択ページは利用者ごとの端末内UI状態。ページ移動はsticky.layoutの既存競合検知を使用。
- 保存／セキュリティ：ログインなしと表示名ベースの区分は維持し、機密情報の禁止警告も維持。既存業務メモ、タスク／予定／ToDo、Classic／JOURNALを変更しない。
- 検証：unit/core/store、Origin Playwright PC/スマホ/キーボード/IME、Firebase emulator、全Protocolと回帰検査。以前の付箋のロードや編集を壊さないこと。
- 公開：検査成功後にPR統合・GitHub Pagesの公開結果確認。変更前のmainコミットを復元先として保持。
