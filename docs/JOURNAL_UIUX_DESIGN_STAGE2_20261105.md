- スマートフォン：Linen / Margin 各1ページ手帳の画面デザイン

## 情報構造
PC (1051px〜)：左インデックス + 今日 / 週間 / ToDo / タスク / 予定 / 業務メモのタブ + 見開き2ページ。今日の左ページに日付・予定、右ページにToDo・タスク・メモを配置。
タブレット (768〜1050px)：無理な見開き縮小を避け、単ページ化。
モバイル (〜767px)：単ページ、下部固定ナビ [今日 / 週間 / ToDo / タスク / その他]。その他から予定・業務メモへ。
