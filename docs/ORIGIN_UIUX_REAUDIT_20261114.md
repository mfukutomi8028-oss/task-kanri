# Origin UI/UX 再監査（2026-11-14、Ver.585基準）

## 目的・制約
Originを「シンプルで洗練され、日常業務に集中できるワークスペース」として磨く。既存のClassic／JOURNALの動作、Firebase保存仕様、権限・リビジョン照合、検索条件と一覧復元を維持する。印象だけで機能を削除しない。

## 使用した評価軸
- Impeccable：情報階層、主要操作、視覚の一貫性、利用時の迷い
- Hallmark：意図的な構成、トークン・フォーカス・モーション・可読性の品質
- UI/UX Pro Max：アクセシビリティ、タッチサイズ、入力、レスポンシブ、状態表示
- Web Interface Guidelines：フォームラベル、キーボード操作、一覧・検索・入力時の回復経路

**評価の根拠**：Ver.585のGitHub Pages配布資産（2026-11-14公開）と、GitHubリポジトリのソース／自動テストを静的に監査した。ブラウザ操作を伴う検証は変更PRのPlaywright CIで実施する。手元ブラウザは管理者制限によりローカルURL・data URLとも遷移を許可しないため、視覚的スクリーンショットの実測・iOS実機操作・200%拡大の実測は**未実施**。Impeccable専用エンジンもネットワーク制限で起動できず、判定は同スキルの評価観点による手動監査であり公式ツールの自動検出結果ではない。未検証の項目を合格扱いしない。

## 次工程追補：モバイル視認性と操作間隔（2026-11-14）

今回の監査では、保存仕様ではなくモバイルで頻繁に触れるナビゲーションと検索入力を優先した。

- **確認・訂正**：初期CSSの「5列指定」は、後段の「6列指定」で上書きされており、Ver.587での実描画では320px・390pxとも6タブが**すでに一列**に収まっていた。初期CSSだけからの「2行になる」という推測は誤りだった。今回、初期CSSを6列へ修正し後段の重複上書きを撤去して単一正本化する。
- **実測した改善余地**：隔たりのないタブのタップ領域、10pxのラベル、13pxの横断検索入力。Playwrightの320px・390pxの合成テスト画面（データはオフラインのテスト用ルーム）で確認。
- **実装**：下部ナビ6項目を維持しながら列間隔8px・ラベル11px・タップ領域44px以上を維持。横断検索・タスク・ToDo・予定・メモの主要入力をスマートフォンで16pxへ統一。全期間検索の入力も16pxへ。
- **検証**：`tests/origin-mobile-clarity-v588.spec.mjs` の320px・390px・1366pxブラウザ検査。修正前のテストで文字サイズと間隔が期待値を満たさないことを確認した。修正後は必須CI・公開後回帰の結果で判定する。
- **維持**：6タブとその遷移、既存配色、キーボードフォーカス、タスク・予定・メモの保存経路、Classic・JOURNAL・Firebaseのデータ契約を変更しない。
- **対象外・残課題**：実機iOS Safariの入力時自動ズーム、200%文字拡大、VoiceOverの読み上げ感覚はこのChrome合成テストだけでは実証できない。必要なら実機確認を別工程にする。
