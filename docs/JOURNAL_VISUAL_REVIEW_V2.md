## 設計成果

独立した手帳型画面「JOURNAL」について、次の4画面の高精細モックを制作した。
- Linen PC（1440x900）: ネイビー×アイボリー、見開き手帳、控えめな罫線とセリフ見出し
- Linen Mobile（390x844）: 1ページ・縦スクロール、固定下部ナビ
- Margin PC（1440x900）: セージグリーン、色付きインデックス、やわらかな角丸、付箋風メモ
- Margin Mobile（390x844）: 1ページ・縦スクロール、控えめな遊び心を残した軽いデザイン

画像・スタンドアロンHTMLモックは、チャットの `JOURNAL_Design_v2.zip` に格納。GitHubへはこのレビュー文書のみ反映。製品実装は未着手。

## 共通の画面構造
- Desktop: サイドメニュー、上部操作領域、リング綴じ風の見開きページ、右端インデックス
- PC左ページ: 日付、未完了/期限超過/今日/自分担当のサマリ、ミニカレンダー、当日の予定
- PC右ページ: 今日のToDo、完了進捗、注目タスク、業務メモ
- Mobile: 日付、サマリ、予定、ToDo、メモを縦並び。下部ナビに今日/週間/ToDo/タスク/メニュー
- 6画面: 今日 / 週間 / ToDo / タスク / 予定 / 業務メモ。HTMLモックでは各ページを模擬切替
- 本番コード接続時には各操作を既存canonical ownerへ委譲。現行の保存・通知・競合制御は複製しない。

注: これはサンプルデータによるデザイン検証であり、現行アプリの本番E2E、Firebase通信、登録・編集・削除の動作確認ではない。
