# POP NOTEBOOK UI v2（デザイン承認用）

現行Classicを維持したまま確認する、手帳・文具風UIの独立モックです。

- `index.html` を開くと、架空データによる画面を確認できます（外部API接続・保存・共有なし）。
- **上部タブ**：今日の手帳 / ToDo / タスク / 予定 / ノート。
- **タスク内**：ボード / 一覧 / タイムライン。カードや行のクリックで詳細表示。
- **予定内**：日 / 週 / 月の切替。今日の手帳から今週表示も可能。
- 手帳表現：インデックス、リング、罫線、貼り紙、ラベル、落ち着いた文具カラー。
- モバイルは1ページ構成で、項目選択により下部の詳細シートを開きます。

## 制約と実装規則

**このモックはデザイン専用**です。画面内のタスク・予定は架空の固定データであり、変更・通知・コメント履歴・検索条件・ユーザーの実データへの書込を提供しません。`app.js` のサンプル配列を本番の保存処理に転用しないでください。

本番Classicの保存・参照処理は `app.js` / `work-features-v167.js` を正本とし、今後の実装でも読み取りアダプターと既存コマンドへの委譲で接続します。

既存機能（タスクの3表示形式、検索・絞込・一括操作、予定の日/週/月・繰返し・コピー、ToDoの作成・完了・履歴、業務メモの編集・固定・ソート・タスク化、通知、コメント、履歴、ルーム設定、競合・失敗処理）は削除せずに継承する前提です。

配色のカスタマイズはUI構造確定後の別工程とし、このモックでテーマ選択設定は実装しません。視覚装飾は操作領域・文字コントラストと両立させます。
