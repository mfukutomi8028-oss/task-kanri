# D案・手帳ワークベンチ UI デザインモック v1.0

- 本モックは `docs/PLANNER_WORKBENCH_UI_DESIGN_V1.md` の**第1工程（デザイン承認）**専用。
- `index.html` をブラウザで開くか、ローカルの静的HTTPサーバーを起動するだけで利用可能。
- 4画面：PC「今日の手帳」「タスク」「ノート」、390pxスマートフォン「今日の手帳」。
- パステルのインデックス、ノートの見開き、一覧から詳細への移動を検証できる。
- サンプルデータはすべて架空で、固定の2026年11月3日として表示する。
- **本番アプリには読み込まれない**。Firebaseアクセス・保存・通信は実装しない。
- 実際の編集・作成・完了・通知はダミー。次工程（Classicへの接続）より前に、本デザインを確認する。
- 本番向けに取り込む際は、このモックのダミーデータやイベントを複製せず、Classicの既存処理を正本として接続する。

## 表示と操作

上部インデックスでページ変更。行を選ぶと右側の詳細を更新。PCでは「今日」「タスク」「ノート」を確認可能。
スマホでは下部ナビ、選択行の詳細シート、44px以上のボタンを確認できる。

## 色と文字

`#F2F5F8` 背景、`#FFFDF8` 紙、`#25374B` 本文、`#425B8D` 主要操作、`#EDF0FB` 選択面を設計書から継承。
本文16px、見出し20-26pxを基準にし、情報密度のため一覧行はおおむね50-64px。
